# Volt Cycle

Full-colour Python 3 neon light-cycle arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a cyan volt cycle that paints a glowing trail. Avoid walls and your own path. Scoop gold / lime / orange orbs for score and a speed boost. Left / Right (or A / D) turn 90°. R restarts.

## Play

```bash
pip install -r requirements.txt
python3 volt_cycle.py --play
```

## Record a 9:16 reel

```bash
python3 volt_cycle.py --record
```

Writes a 1080×1920 h264 clip (15 s @ 30 fps) with title, score, and `x.com/ElbowOS` burned into the frames.
